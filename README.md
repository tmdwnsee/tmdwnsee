## 안녕하세요, AI 엔지니어를 목표로 하는 이승준입니다. 👋

**문제를 구조화하고, AI 기술을 실제 서비스 흐름에 연결하는 개발자**를 지향합니다.

정보통신공학을 전공했으며, RAG 검색 파이프라인과 LLM 기반 워크플로를 구현하는 프로젝트를 진행했습니다. 문서 구조에 맞는 전처리, 검색·생성 단계의 연결, 평가 결과를 바탕으로 한 병목 개선에 관심이 있습니다.

- **RAG & Retrieval** — PDF 요구사항 구조 분석, 하이브리드 검색, 검색 품질 평가
- **LLM Application** — 구조화된 출력, Tool 연동, 단계별 데이터 흐름 설계
- **Engineering** — 데이터 파이프라인 구현, 데이터베이스 연동, 성능 측정 및 개선
